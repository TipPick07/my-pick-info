## 📌 핵심 요약 — 읽기 전에 먼저 확인

| 구분 | 이동환 (국민의힘·현직) | 이재준 (더불어민주당·전 시장) |
|------|-------------------|----------------------|
| 재건축 용적률 | **최대 500%** 파격 상향 | **350% 내외** 적정 용적률 |
| 분담금 | 일반분양 극대화 → **분담금 대폭 감소** | 공공기여 연계 복지 인프라 확충 |
| 이주 대책 | 이주비 대출 이자 **시에서 직접 지원** | 창릉 신도시 연계 **이주 시기 분산** |
| 자족도시 | 경제자유구역 + 바이오기업 대거 유치 | 킨텍스 3전시장·K컬처밸리 문화 일자리 |
| **사전투표** | **5월 29~30일** | **본투표 6월 3일** |

## 일산의 부활, 누가 더 빠르고 돈 덜 들게 해낼까

'천당 아래 분당, 그 옆에 일산'이라는 말이 무색해진 지 오래입니다. 낡은 배관, 심각한 주차난, 분당과 벌어지는 집값 격차 — 고양 시민들의 상실감이 컸습니다. 그런데 **노후계획도시 특별법**이라는 강력한 무기가 생겼습니다.

재선에 도전하는 **이동환 현 시장**은 용적률 500% 파격 상향과 이주비 이자 지원으로 분담금을 최소화하겠다고 합니다. 리턴매치를 준비하는 **이재준 전 시장**은 350% 적정 용적률과 창릉 연계 순환 정비로 전세 폭등 없이 안정적으로 추진하겠다는 전략입니다.

## 핵심 공약 비교표

| 정책 분야 | 이동환 | 이재준 |
|---------|------|------|
| **재건축 용적률** | **최대 500%** 파격 상향, 선도지구 혜택 확대 | 350% 내외 적정 용적률 + 기반시설 연계 |
| **인허가 속도** | 인허가 기간 **절반 단축** | 순환 정비 방식으로 교통·환경 영향 최소화 |
| **이주비 지원** | 조합원 이주비 대출 이자 **시에서 직접 지원** | 창릉 신도시 연계 이주 시기 분산 |
| **자족도시** | 경제자유구역 최종 지정, 글로벌 바이오·정밀의료 기업 유치 | 킨텍스 제3전시장 MICE 산업 + K컬처밸리 정상화 |
| **교통** | 9호선 급행 고양 연장, 신분당선 서북부 연장 재추진 | 덕양-일산 트램 신설, 철도 소외지 마을버스 준공영제 |

## 💰 가구별 연간 수혜액 시뮬레이션

### Case 1 — 일산동구 30년 차 노후 아파트 소유 60대 은퇴자

| 항목 | 이동환 당선 시 | 이재준 당선 시 |
|------|------------|------------|
| 재건축 분담금 | 용적률 500% → 일반분양 극대화 → **수천만 원 절감 가능** | 350% 적정 개발 → 분담금 상대적 높을 수 있음 |
| 이주비 대출 이자 | **시에서 직접 지원** → 연 수백만 원 절감 | 이주 단지 연계로 전세비 안정 |
| 재건축 완료 시 자산 가치 | 고밀도 개발 → 자산 급등 가능성 | 쾌적한 주거 환경 유지 → 안정적 상승 |

→ **분담금 최소화·이주비 절감이 시급한 자금 부담 소유자**라면 이동환 후보 금융 지원이 직접 체감됨.

---

### Case 2 — 일산서구 전세 30대 직장인 (재건축 기간 이주 예정)

| 항목 | 이동환 당선 시 | 이재준 당선 시 |
|------|------------|------------|
| 재건축 기간 전세 | 이주 수요 집중 → 전세 폭등 위험 | 창릉 연계 순환 정비 → **전세 폭등 방지** |
| 직주근접 | 경제자유구역 바이오 기업 입주 시 일산 내 취업 기회 | 킨텍스 MICE 문화 일자리 |
| **주거 안정성** | 이주비 지원 받아도 전셋값 오르면 부담 | **세입자 주거 안정 직접 보호** |

→ **전세 거주 세입자**라면 이재준 순환 정비로 임시 주거비 폭등을 막는 게 더 유리.

---

### Case 3 — 덕양구 40대 자영업자

| 항목 | 이동환 당선 시 | 이재준 당선 시 |
|------|------------|------------|
| 교통 | 신분당선 연장 → 덕양구 접근성 ↑ → 부동산 가치 상승 | 덕양-일산 트램 → 덕양구 상권 인구 유입 |
| 상권 | 광역 교통망 개통 시 외부 인구 유입 낙수 효과 | 균형 발전 예산으로 덕양구 직접 투자 |
