## 📌 핵심 요약 — 읽기 전에 먼저 확인

| 구분 | 오세훈 (국민의힘·현직) | 박주민 (더불어민주당) |
|------|-------------------|-----------------|
| 핵심 슬로건 | 자산 가치 상승·인프라 고도화 | 무주택자 보호·주거비 직접 절감 |
| 재건축 | **모아타운·신속통합기획 전면 확대·재초환 완화** | 역세권 공공임대 고밀 확대·기부채납 강화 |
| 교통 | **기후동행카드 전국 수도권 연계 완성·요금 동결** | K-패스 연계 서울형 통합 패스·65세 무임승차 유지 |
| 청년 주거 | 역세권 민간 공급 확대 (중장기 가격 안정) | **역세권 공공임대 + 무주택 1인 가구 월세 지원 강화** |
| 소상공인 | 저금리 대환대출 + 로컬브랜드 육성 | **서울사랑상품권 2배 확대** → 골목상권 소비 직접 증대 |
| **사전투표** | **5월 29~30일** | **본투표 6월 3일** |

## 내 지갑과 자산, 어느 후보가 더 지켜줄까

재건축 분담금과 매월 나가는 교통비·주거비 — 서울시장 선거는 이 두 가지를 누가 더 잘 해결하느냐의 싸움입니다. **오세훈 현 시장**은 재건축 속도전과 기후동행카드로 자산 가치와 교통비를 동시에 잡겠다고 합니다. **박주민 의원**은 공공임대 대폭 확대와 청년 월세 직접 지원으로 주거 취약계층의 지갑을 지키겠다는 전략입니다.

## 핵심 공약 비교표

| 정책 분야 | 오세훈 | 박주민 |
|---------|------|------|
| **재건축·재개발** | **모아타운·신속통합기획 전면 확대**, 재초환 완화 추진 | 역세권 고밀도 공공임대 대량 확대, 기부채납 강화 |
| **교통** | **기후동행카드 전국 수도권 연계 완성·요금 동결** | K-패스 연계 서울형 통합 패스 도입 |
| **청년·무주택** | 민간 역세권 소형 주택 공급 확대 → 중장기 가격 안정 | **역세권 공공임대 + 무주택 1인 가구 월세 지원 강화** |
| **돌봄** | 손주돌봄수당(조부모 돌봄수당) 인상, 서울형 키즈카페 확충 | 24시간 공공 돌봄센터 의무 설치, 보육교사 처우 개선 |
| **소상공인** | 저금리 대환대출 + 로컬브랜드 육성 지원 | **서울사랑상품권 발행 2배** → 골목상권 소비 직접 유입 |

## 💰 가구별 연간 수혜액 시뮬레이션

### Case 1 — 30대 무주택 1인 가구 (대중교통 출퇴근)

| 항목 | 현재 | 오세훈 당선 시 | 박주민 당선 시 |
|------|------|------------|------------|
| 월 교통비 | 약 7만 원 | **기후동행카드 완성 → 월 6만 2천 원** (경기 연계) | K-패스 통합 패스 |
| 월 주거비 (월세) | 약 90만 원 | 민간 공급 → 중장기 안정 | **월세 지원 강화 → 월 20만 원 절감** |
| **연간 예상 절감** | — | 교통비 연 1만 원 수준 | **월세 연 240만 원** |

→ 당장 월세 부담이 급한 청년이라면 박주민 월세 지원이 연 240만 원 즉각 체감.

---

### Case 2 — 50대 재건축 대기 노후 아파트 소유 맞벌이

| 항목 | 오세훈 당선 시 | 박주민 당선 시 |
|------|------------|------------|
| 재건축 분담금 | **재초환 완화 → 수천만 원 절감** | 공공기여 강화 → 분담금 상대적 높을 수 있음 |
| 인허가 속도 | 신속통합기획 → **단축** | 공공임대 비율 협상 필요 |
| 돌봄비 | 손주돌봄수당 인상 | 24시간 공공 돌봄센터 → 장기적 돌봄비 절감 |

→ 재건축 분담금 최소화가 목표라면 오세훈 재초환 완화가 수천만 원 직접 절감.

---

### Case 3 — 마포구 40대 소상공인 (음식점)

| 항목 | 오세훈 당선 시 | 박주민 당선 시 |
|------|------------|------------|
| 대출 이자 | **저금리 대환대출** → 이자 부담 직접 ↓ | — |
| 매출 | 로컬브랜드 육성으로 브랜딩 지원 | **서울사랑상품권 2배 → 골목 소비 급증** |
| **즉각 효과** | 이자 절감 | 상품권 소비 증가 → 매출 즉각 ↑ |

| 모아타운 후보지 거주 | 오세훈 | 저층 노후 → 신축 전환 자산 급등 |
| 대중교통 광역 이용, 경기 연계 필요 | 오세훈 | 기후동행카드 전국 연계 완성 |
| 당장 월세 부담 큰 청년 무주택자 | 박주민 | 월세 지원 연 240만 원 절감 |
| 골목상권 매출 즉각 증대 원함 | 박주민 | 서울사랑상품권 2배 → 소비 직접 유입 |
| 무주택 첫 내 집 마련 목표 | 박주민 | 역세권 공공임대 대량 공급 |
