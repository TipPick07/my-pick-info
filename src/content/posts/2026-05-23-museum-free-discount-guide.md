## 문화생활, 꼭 돈 써야 즐길 수 있을까요?

수도권에는 입장료 없이, 또는 매우 저렴하게 즐길 수 있는 국공립 박물관과 미술관이 생각보다 훨씬 많습니다. 국립중앙박물관 상설 전시는 완전 무료이고, 국립현대미술관은 일주일에 두 번 야간 무료 입장이 가능합니다. 2026년 4월부터는 '문화가 있는 날'이 매월 마지막 수요일에서 **매주 수요일**로 확대되면서 혜택 받을 기회도 4배나 늘었습니다.

이 글에서는 서울·인천·경기 주요 국공립 박물관·미술관의 무료·할인 입장 조건을 한눈에 비교하고, 조건별로 어디를 가면 가장 이득인지 정리했습니다.

## 🏛️ 시설별 상세 가이드

### 1. 국립중앙박물관 — 상설전 무조건 무료

서울 용산구에 위치한 국립중앙박물관은 대한민국 최대 규모의 박물관입니다. 선사 시대부터 조선 시대까지 방대한 유물을 전시하는 **상설전시는 누구든 무료**로 관람할 수 있습니다. 다만 특별기획전은 별도 입장권이 필요합니다.

| 항목 | 내용 |
|------|------|
| 주소 | 서울 용산구 서빙고로 137 |
| 운영시간 | 월·화·목·금·일 10:00~18:00, 수·토 10:00~21:00 |
| 상설전 입장료 | 무료 |
| 교통 | 지하철 4호선 이촌역 2번 출구 도보 5분 |
| 주차 | 1,000대 가능 (유료, 2시간 무료) |
| 홈페이지 | [museum.go.kr](https://www.museum.go.kr) |

> **에디터 팁:** 2027년부터 유료화 전환이 논의되고 있는 만큼, 지금이 가장 좋은 시기입니다. 특히 수요일·토요일 야간(18~21시)에는 박물관 내 레스토랑과 뮤지엄샵도 함께 이용할 수 있어 데이트 코스로 인기입니다.

---

### 2. 국립현대미술관 서울관 — 수·토 야간 무료의 매력

경복궁 옆 종로구에 위치한 국립현대미술관 서울관은 국내외 현대미술 작품을 전시합니다. 2026년 현재 데이미언 허스트 전시(3/20~6/28)가 진행 중입니다.

| 항목 | 내용 |
|------|------|
| 주소 | 서울 종로구 삼청로 30 |
| 운영시간 | 월·화·목·금·일 10:00~18:00, 수·토 야간개장 10:00~21:00 |
| 일반 입장료 | 전시 1건 2,000~5,000원, 통합 7,000원 |
| **수·토 야간 무료** | 오후 6시~9시 무료 발권 |
| **24세 이하 무료** | 신분증 제시 시 언제나 무료 |
| **대학생 무료** | 학생증 제시 시 무료 |
| 교통 | 지하철 3호선 안국역 1번 출구 도보 5분 |
| 홈페이지 | [mmca.go.kr](https://www.mmca.go.kr) |

서울 중구 서소문에 위치한 서울시립미술관은 상설 전시를 **무료**로 운영합니다. 2026년 5월 19일부터 10월 25일까지 한국 추상미술의 거장 **유영국 회고전 《산은 내 안에 있다》**가 개최 중입니다.

| 운영시간 | 화~일 10:00~20:00 (월요일 휴관) |
| 상설전 입장료 | **무료** |
| 현재 전시 | 《유영국: 산은 내 안에 있다》 (~2026.10.25) |

## 🗓️ 무료·할인 혜택 일정 정리

### 문화가 있는 날 — 이제 매주 수요일!

2026년 4월 1일부터 '문화가 있는 날'이 **매주 수요일**로 확대되었습니다. 기존에는 매월 마지막 주 수요일에만 적용되었지만, 이제 4주 내내 혜택을 받을 수 있습니다.

| 항목 | 내용 |
|------|------|
| 적용 날짜 | 매주 수요일 |
| 혜택 내용 | 국공립 박물관·미술관 무료 또는 할인, 공연 할인 등 |
| 참여 시설 | 수십 개 문화시설 (시설별 상이) |
| 확인 방법 | 각 시설 홈페이지 또는 문화포털(culture.go.kr) |

### KB 무료 관람 프로젝트

KB금융그룹이 운영하는 'KB 무료 관람 프로젝트'를 통해 전국 40여 개 공립 박물관·미술관을 무료로 관람할 수 있습니다. KB스타뱅킹 앱의 '국민지갑' 서비스를 통해 신청 가능합니다.

| 항목 | 내용 |
|------|------|
| 이용 조건 | KB스타뱅킹 앱 설치 + 국민지갑 등록 |
| 적용 시설 | 전국 40여 개 공립 박물관·미술관 |
| 혜택 | 지정 시설 무료 관람 |

## 💡 상황별 추천 코스

### 평일 직장인 퇴근 코스 (무료·저렴)
→ **국립현대미술관 서울관** 수·토 야간(18~21시 무료) + 근처 삼청동 카페

### 주말 가족 나들이 (아이와 함께)
→ **국립중앙박물관** 상설전 무료 관람 + 박물관 내 식당 점심

### 데이트 코스 (서울 도심)
→ **서울시립미술관** 유영국 전시 무료 → 덕수궁 돌담길 산책 → 덕수궁 커피숍

### 수도권 서부 거주자
→ **서서울미술관**(강서) 또는 경기 **인천시립박물관** (무료)

## 팁픽 에디터의 결론

수도권에서 무료로 즐길 수 있는 문화시설은 생각보다 훨씬 많습니다. 국립중앙박물관과 서울역사박물관은 예약 없이 언제든 무료이고, 국립현대미술관은 수요일·토요일 야간만 잘 활용하면 유료 전시도 공짜로 볼 수 있습니다.

특히 **매주 수요일로 확대된 문화가 있는 날** 제도는 2026년부터 적용된 큰 변화입니다. 한 달에 한 번밖에 못 챙기던 혜택을 이제 매주 챙길 수 있게 된 것입니다.

혜택 정보는 시설별로 수시로 바뀌므로, 방문 전 해당 시설 홈페이지에서 최신 정보를 확인하는 습관을 들이시기 바랍니다.
