## 사전투표 놓쳤다고 걱정하지 마세요

5월 29~30일 사전투표 기간을 놓치셨더라도 6월 3일 본투표일이 남아 있습니다. 본투표일은 공직선거법에 따른 법정 공휴일로 지정되어 있어 대부분의 직장인과 학생이 참여할 수 있습니다. 단, 본투표는 사전투표와 달리 **반드시 주민등록상 주소지 기준으로 배정된 지정 투표소**에서만 투표할 수 있다는 점을 반드시 확인해두어야 합니다. 다른 투표소를 찾아가면 투표 자체가 불가합니다.

## ✅ D-3 최종 체크리스트 (오늘 바로 확인)

### 1단계 — 내 투표소 위치 확인

투표소는 선거 전 발송된 투표안내문(엽서)에 적혀 있습니다. 안내문을 분실했거나 받지 못한 경우 아래 방법으로 바로 확인하세요.

| 방법 | 경로 |
|---|---|
| 선관위 홈페이지 | nec.go.kr → '투표소 찾기' 클릭 |
| 선거정보 앱 | '선거정보' 앱 설치 후 주소 입력 |
| 네이버·카카오맵 | '내 투표소 찾기' 검색 |
| 전화 문의 | 선거법 위반 신고·안내: ☎ 1390 |

> ⚠️ 사전투표소와 본투표소는 위치가 다릅니다. 반드시 '본투표소'를 확인하세요.

### 2단계 — 신분증 준비

관공서 또는 공공기관에서 발행한 **사진이 부착된 신분증**이면 종류 무관하게 인정됩니다.

| 인정되는 신분증 | 비고 |
|---|---|
| 주민등록증 | 가장 일반적 |
| 운전면허증 | ✅ |
| 여권 | ✅ |
| 국가·지자체 발급 복지카드, 장애인등록증 | ✅ (사진 부착 시) |
| 모바일 주민등록증 (공식 앱) | ✅ |
| 주민등록증 임시발급증명서 | 분실 시 주민센터에서 즉시 발급 가능 |

> 💡 신분증을 분실했다면 6월 2일(화)까지 가까운 주민센터에서 임시발급증명서를 발급받아 준비해두세요.

### 3단계 — 후보 공약 미리 확인

투표소 안에서는 후보를 검색하거나 공약을 찾아볼 수 없습니다. 아래 공식 경로에서 미리 확인해두세요.

- **정책·공약마당**: policy.nec.go.kr
- **선관위 후보 정보**: nec.go.kr → 후보자 정보 조회
- **각 후보 공식 선거 홈페이지**

### 4단계 — 방문 시간대 전략

| 시간대 | 혼잡도 | 추천 여부 |
|---|---|---|
| 오전 6시~7시 | 낮음 | ✅ 일찍 가고 싶다면 |
| 오전 7시~9시 | 높음 (출근 전 집중) | ⚠️ 대기 예상 |
| 오전 10시~오후 2시 | 가장 한산 | ✅ 최적 |
| 오후 5시~6시 | 높음 (마감 전 집중) | ⚠️ 대기 예상 |

## 투표용지 7장, 당황하지 않는 법

수도권(서울·인천·경기) 유권자는 이번 지방선거에서 기본 **7장의 투표용지**를 받습니다. 처음 보면 당황스러울 수 있지만 원칙은 하나입니다. **용지 한 장당 반드시 한 명(또는 정당 하나)에게만 기표**합니다.

| 투표용지 | 선출 대상 | 기표 방식 |
|---|---|---|
| 1장 | 시·도지사 (서울시장·인천시장·경기도지사) | 후보 1명 선택 |
| 2장 | 교육감 | 후보 1명 선택 |
| 3장 | 시·군·구청장 | 후보 1명 선택 |
| 4장 | 광역의원 지역구 | 후보 1명 선택 |
| 5장 | 광역의원 비례대표 | 정당 1개 선택 |
| 6장 | 기초의원 지역구 | 후보 1명 선택 (2~4인 선거구) |
| 7장 | 기초의원 비례대표 | 정당 1개 선택 |

> ⚠️ 국회의원 재·보궐선거가 함께 치러지는 지역은 1장 추가되어 최대 8장. 무투표 당선 선거구는 해당 용지 미교부.

**기표 실수 방지 핵심 원칙:**
- 기표는 투표소 안에 비치된 기표용구(도장)로만 합니다
- 다른 필기구 사용 시 무효 처리
- 두 명에게 기표하거나 기표란 외에 표시하면 무효
- 실수한 경우 즉시 투표사무원에게 알리면 투표용지 교환 가능 (투표함 투입 전에만 가능)

## 투표 당일 현장 흐름

1. 지정 투표소 도착 → 줄서기
2. 신분증 제시 → 선거인 명부 서명 또는 지장 날인
3. 투표용지 7장 수령
4. 기표소 이동 → 각 용지에 1명(1정당)씩 기표
5. 투표지를 각 투표함에 투입
6. 퇴장

전체 소요 시간은 대기 없을 때 기준 **3~5분** 수준입니다.

## 📝 팁픽 에디터의 결론

사전투표를 놓쳤더라도 6월 3일 본투표일이 법정공휴일이라 참여 기회는 충분합니다. 오늘(D-3) 해야 할 일은 딱 두 가지입니다. 첫째, nec.go.kr에서 내 지정 투표소 위치 확인. 둘째, 신분증 위치 확인. 이 두 가지만 해두면 당일 헤매는 일은 없습니다. 공약 비교는 policy.nec.go.kr에서 미리 확인해두면 7장의 투표용지 앞에서 당황하지 않습니다.
