# 배포 후 검색엔진 작업 체크리스트 (구글·네이버)

> 큰 개편 후 한 번만 해두면 되는 작업. 위에서부터 순서대로.
> 도메인: https://tip-pick.com · 사이트맵: https://tip-pick.com/sitemap.xml

---

## 0단계. 배포부터 확인 (이게 먼저!)
- [ ] 본인 PC에서 `git push` (GitHub Desktop이면 "Push origin")
- [ ] 몇 분 뒤 https://tip-pick.com 접속 → 새 메뉴(경제·지원금·계산기)와 계산기 4개가 보이면 배포 완료
- [ ] (안 바뀌어 보이면 Ctrl+F5로 새로고침, 그래도 안 되면 Cloudflare 빌드 상태 확인)

검색엔진은 "라이브 사이트"만 봅니다. 배포 전에는 아래 작업 의미 없음.

---

## A. 구글 서치콘솔 (search.google.com/search-console)

### A-1. 사이트맵 다시 제출
- [ ] 좌측 메뉴 **색인 생성 → Sitemaps**
- [ ] "새 사이트맵 추가" 칸에 **`sitemap.xml`** 입력 → **제출**
- [ ] 상태가 **"성공"** 으로 뜨는지 확인 (이미 등록돼 있어도 구조가 바뀌었으니 다시 제출)

### A-2. 핵심 페이지 색인 요청 (하루 약 10개 제한)
상단 **"URL 검사"** 칸에 아래 주소를 하나씩 넣고 → **"색인 생성 요청"** 클릭.
- [ ] https://tip-pick.com/
- [ ] https://tip-pick.com/money/
- [ ] https://tip-pick.com/benefits/
- [ ] https://tip-pick.com/tools/
- [ ] https://tip-pick.com/tools/salary/
- [ ] https://tip-pick.com/tools/loan/
- [ ] https://tip-pick.com/tools/income-tax/
- [ ] https://tip-pick.com/tools/insurance/
- [ ] https://tip-pick.com/guides/
- [ ] (남으면 다음 날) 경제 글: /blog/2026-06-27-net-salary-2026-guide/ 등

> 하루 한도에 걸리면 "할당량 초과" 표시 → 다음 날 이어서 하면 됩니다.

### A-3. 삭제한 축제 글의 404 — 정상입니다 (겁먹지 말 것)
- [ ] 며칠 뒤 **색인 생성 → 페이지** 에 "찾을 수 없음(404)"이 수십 개 떠도 **정상**
  (지운 글이라 당연. 구글이 시간 지나며 알아서 제외함. 손 안 대도 됨)
- [ ] (선택) 빨리 빼고 싶으면 **색인 생성 → 삭제 → 새 요청**에서 개별 URL 임시 삭제

### A-4. 며칠~2주 후 점검
- [ ] **페이지** 보고서에서 "색인 생성됨" 숫자가 늘어나는지 확인

---

## B. 네이버 서치어드바이저 (searchadvisor.naver.com)

### B-0. (처음이면) 사이트 등록 + 소유확인
- [ ] 로그인 → 우측 상단 **웹마스터 도구**
- [ ] 사이트 추가에 `https://tip-pick.com` 입력
- [ ] 소유확인은 **HTML 메타태그 방식**이 편함 → 안내된 태그를 사이트 `<head>`에 넣어야 하면 말해주세요(제가 넣어드림)
- [ ] (이미 등록돼 있으면 이 단계 건너뜀)

### B-1. 사이트맵 제출
- [ ] 좌측 **요청 → 사이트맵 제출**
- [ ] 칸에 **`sitemap.xml`** 입력 → **확인**

### B-2. 웹페이지 수집 요청
- [ ] 좌측 **요청 → 웹페이지 수집**
- [ ] A-2의 핵심 URL을 개별로 제출 (하루 한도가 적으니 홈·계산기부터)

### B-3. robots.txt 확인 (확인만)
- [ ] **검증 → robots.txt** — 이미 정상(크롤 허용 + 사이트맵 링크). 문제 없으면 패스

> 네이버는 수집·반영에 **약 2주** 걸립니다. 바로 안 떠도 정상.

---

## C. 안 해도 되는 것 (안심 포인트)
- 숨긴 카테고리(핫이슈·나들이·꿀팁)는 **noindex + 사이트맵 제외** 상태 → 검색에 안 잡힘. 따로 막을 필요 없음.
- 나중에 **애드센스 승인** 받으면 `APPROVAL_MODE`를 끄는데(숨긴 카테고리 공개), 그때 **사이트맵만 양쪽에 다시 제출**하면 됨.

## D. 애드센스 (검색엔진과 별개)
- 배포 후 adsense.google.com → 사이트 추가 → 심사 신청.
- 서치콘솔에 색인돼 있으면 "실제 크롤되는 사이트"라는 신호라 심사에 유리.
