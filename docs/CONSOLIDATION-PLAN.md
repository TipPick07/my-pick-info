## 실행 절차 (순서 고정)

1. **8/9 '색인 생성됨' 목록과 대조** → 색인된 글은 대상에서 제외하고 목록에 기록.
2. **자체 계산 회수** — 흡수될 글의 §1-6 자체 계산·비교표를 먼저 뽑아 통합 글에 옮긴다. **원본성 총량이 줄면 통폐합의 의미가 없다.**
3. **통합 글 작성** — 헤드 키워드를 §1-8 규칙대로 제목 앞·description·도입·H2에 반복. H2는 기존 611개와 중복 0 유지.
4. **301 등록** — `public/_redirects`에 **후속 글로 직접** 보낸다(`/blog/` 허브로 보내지 말 것 — 신호가 흩어짐). 슬래시 변형도 같이 등록.
   ```
   /blog/<옛슬러그>   /blog/<새슬러그>/   301
   /blog/<옛슬러그>/  /blog/<새슬러그>/   301
   ```
5. **내부 링크 정리** — 삭제되는 슬러그를 가리키는 기존 글의 링크를 전부 새 글로 교체(`grep -rl` 로 확인).
6. **검증** — 게이트 · H2 중복 0 · 빌드 · 사이트맵 URL 수 · 깨진 내부 링크 0.
7. **색인 요청** — 통합 글을 최우선으로 재요청하고, 301 처리된 옛 URL은 요청하지 않는다.
