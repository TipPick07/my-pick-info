## 0. 한 줄 정체성 (현재)
**전국 생활·금융 정보 잡블로그.** 정부 지원금·경제·세금·실생활 계산기를 비전문가 눈높이로 직접 정리한다. 구글 애드센스로 수익화한다. (지역·운영자 이름 노출 없음.)

## 1. 큰 전환 (2026-06-27)
원래 **'수도권 팁픽'** = 공공데이터포털을 매일 크롤링해 수도권 축제·지원금을 자동 발행하던 사이트. 공공데이터의 한계로 **전국 잡블로그**로 대전환했다.
- 공공데이터 **크롤 자동배포 중지**(손글 전환)
- 수도권 축제 글·크롤 데이터 **전부 삭제**
- 지역 표시(수도권/전국/서울·인천·경기)·운영자 이름·공공데이터 문구 **전부 제거**
- 새 카테고리 구조 + 계산기 + 깔끔한 글 템플릿으로 재편

## 2. 기술 스택
- Next.js(App Router) **정적 export**(`output: "export"`), TypeScript, Tailwind v4
- 호스팅: Cloudflare Pages. 배포: `.github/workflows/deploy.yml` — **push 또는 수동 실행 시에만** 빌드·배포(크롤 크론 제거됨)
- 콘텐츠: 블로그 글 = `src/content/posts/*.md`(gray-matter). 가이드 = `src/app/guides/<slug>/page.tsx` 독립 라우트.

## 3. 정보구조(IA) — `src/config/categories.ts` 가 단일 진실
이 파일 하나가 메뉴·홈·사이트맵·썸네일을 전부 제어한다.

**가장 중요한 스위치: `APPROVAL_MODE`**
- `true`(지금) → 경제·지원금·계산기만 노출. 핫이슈·나들이·꿀팁 숨김(메뉴·홈·검색 제외).
- 애드센스 **승인 메일 받는 날 `false`로** → 6개 카테고리 전부 자동 오픈. (트로이목마 전략)

| 카테고리 | 주소 | 승인 중 |
|---|---|---|
| 돈이 되는 경제 | /money | 공개 |
| 정부 지원금 | /benefits | 공개 |
| 실생활 계산기 | /tools | 공개 |
| 오늘의 핫이슈 | /hot | 숨김 |
| 나들이·핫플 | /festivals | 숨김 |
| 알쓸 꿀팁 | /tips | 숨김 |

가이드(/guides)는 카테고리가 아닌 별도 메뉴.

## 5. 새 글 쓰는 규칙
> ⭐ **카테고리별 상세 양식·체크리스트·표준 예시 파일은 `docs/WRITING-GUIDE.md`가 SSOT**다. 어떤 툴·어디서든 그 문서 + 이 인수인계서를 따르면 양식이 유지된다. 아래는 핵심 요약.

`src/content/posts/YYYY-MM-DD-english-name.md` 생성. frontmatter:
```
title / date / summary / description
category: 경제      # 경제→/money, benefit·정보→/benefits
tags: [..]
officialCurationNote: "..."   # ⭐ 에디터 한마디(선택)
```
- **이미지 필드 넣지 말 것** → 자동으로 카테고리 색 썸네일(경제=초록 💰). 글마다 이미지 불필요.
- 본문은 `##` 헤딩 + 표 + 내부링크(/tools·/money·/benefits). 수치엔 "2026 기준" + 면책 문구.
- 사실·숫자는 공식 자료로 확인, 확실치 않으면 단정 금지.
- **(절대 규칙, 2026-07-20 개정) 같은 카테고리의 '의미 뼈대'를 따르되 H2 문구는 글마다 변주한다.** 뼈대: 도입(숫자 즉답) → 비교/요약 표 → 핵심 섹션 → FAQ → 마무리(내부링크) → 면책. `한눈에 비교`·`마무리` 같은 고정 라벨을 그대로 복사하지 말 것(대량 템플릿 지문 방지) — 상세는 `docs/WRITING-GUIDE.md` **§1-7**(구글 친화 스타일, 운영자 확정).
- **(체류시간 규칙) 글 안에서 관련 글로 자연스럽게 넘어가는 내부 링크(글→글 루프)를 넣는다.** `## 마무리`에 형제 글 1~2개 + 본문 맥락 링크. 하단 '함께 읽으면 좋은 글'(자동, 같은 category 우선) 루프 유지.
- **(⭐ 원본성 규칙, 2026-07-14 신설 — 최우선) 모든 신규 글·보강 글에 '자체 계산 예시(검산)'는 무조건 + 상황별 시나리오/자체 조합 비교표/경계 사례 FAQ 중 1개 이상.** 공식 자료 재정리만 한 글은 발행 금지. 상세 기준은 `docs/WRITING-GUIDE.md` **§1-6**(신규·보강 완성 기준 동일). 애드센스 5차 거부 실원인('원본성 0 + 균일 템플릿 대량 발행') 대응 규칙.

## 7. 운영·배포 규칙
- **커밋·푸시는 운영자 지시 시에만.**(자동 안 함)
- 크롤 자동 크론 없음 → push할 때만 Cloudflare 배포.
- 빌드는 운영자 PC 또는 CI에서 `npm run build`. prebuild가 validate-content·build-search-index 실행.
- **⭐ 일일 발행 루틴(2026-07-20 운영자 확정 — 날짜 트리거 방식, 월·목 발행제 대체)**:
  - **운영자가 챗에 날짜만 치면(예: "7/21") 그날 발행 시작.** AI는 ① 전일 발행 카테고리를 확인(HANDOVER 로그·`src/content/posts/` 날짜 파일·git log)하고 ② **교대 클러스터**로 작성한다:
    - **A형: 경제 글 1편 + 가이드 1편** ↔ **B형: 지원금 글 1편 + 계산기 1편** (전일이 A였으면 오늘 B, B였으면 A)
    - 7/20 = B형(청년내일저축 글+계산기) 발행 → **7/21 = A형 차례**
  - 진행 방식: 주제 후보 2~3개 제안(추천 1개 명시) → 운영자 선택 → WRITING-GUIDE(§1-6·§1-7) 그대로 작성 → 클러스터 상호 내부링크 → 검증(게이트·NUL·tsc·검산) → HANDOVER 로그 → 커밋·푸시는 지시 대기.
  - 발행 후: 신규 2 URL은 **당일 색인 요청 몫**(INDEXING-QUEUE의 '신규 2+백로그 3' 슬롯)으로 운영자에게 전달 + 오픈챗 요약(§7 양식) 필요 시 작성.
  - ※ 계산기는 "정확히 계산되는 주제만"(WRITING-GUIDE §3) — B형 날 적합한 계산기 소재가 없으면 가이드로 대체 제안.
  - **화·수 = 기존 글 보강** → ✅ **전량 완료(2026-07-14, 1~6차 36편 완주 — 로그 (11) 참조)**. 잔여 큐 0. 이후 화·수 슬롯은 성과 기반 리라이트·클러스터 준비 등으로 재지정(운영자 결정).
  - **금 = 색인 점검**(주중 발행분 URL 검사 재확인) + 가벼운 보강 1편. **토 = 오픈챗 공유만.** **일 09:00 = 캡처 8종 → 재신청 게이트 판정**(클라우드 루틴 리마인더) + 다음 주 클러스터 주제 선정.
  - 매일 공통: 아침 git pull → GSC·네이버 1분 체크 → 오픈챗 공유 1건(발행일 새 글 / 그 외 기존 계산기·가이드 순환). 발행 글은 "다른 데 없는 조합"(자체 계산 예시·상황 시나리오·비교표) 1개 이상 필수.
