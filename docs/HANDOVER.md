## 0. 한 줄 정체성 (현재)
**전국 생활·금융 정보 잡블로그.** 정부 지원금·경제·세금·실생활 계산기를 비전문가 눈높이로 직접 정리한다. 구글 애드센스로 수익화한다. (지역·운영자 이름 노출 없음.)

## 1. 큰 전환 (2026-06-27)
원래 **'수도권 팁픽'** = 공공데이터포털을 매일 크롤링해 수도권 축제·지원금을 자동 발행하던 사이트. 공공데이터의 한계로 **전국 잡블로그**로 대전환했다.
- 공공데이터 **크롤 자동배포 중지**(손글 전환)
- 수도권 축제 글·크롤 데이터 **전부 삭제**
- 지역 표시(수도권/전국/서울·인천·경기)·운영자 이름·공공데이터 문구 **전부 제거**
- 새 카테고리 구조 + 계산기 + 깔끔한 글 템플릿으로 재편

## 2. 기술 스택
- Next.js(App Router) **정적 export**(`output: "export"`), TypeScript, Tailwind v4
- 호스팅: Cloudflare Pages. 배포: `.github/workflows/deploy.yml` — **push 또는 수동 실행 시에만** 빌드·배포(크롤 크론 제거됨)
- 콘텐츠: 블로그 글 = `src/content/posts/*.md`(gray-matter). 가이드 = `src/app/guides/<slug>/page.tsx` 독립 라우트.

## 3. 정보구조(IA) — `src/config/categories.ts` 가 단일 진실
이 파일 하나가 메뉴·홈·사이트맵·썸네일을 전부 제어한다.

**가장 중요한 스위치: `APPROVAL_MODE`**
- `true`(지금) → 경제·지원금·계산기만 노출. 핫이슈·나들이·꿀팁 숨김(메뉴·홈·검색 제외).
- 애드센스 **승인 메일 받는 날 `false`로** → 6개 카테고리 전부 자동 오픈. (트로이목마 전략)

| 카테고리 | 주소 | 승인 중 |
|---|---|---|
| 돈이 되는 경제 | /money | 공개 |
| 정부 지원금 | /benefits | 공개 |
| 실생활 계산기 | /tools | 공개 |
| 오늘의 핫이슈 | /hot | 숨김 |
| 나들이·핫플 | /festivals | 숨김 |
| 알쓸 꿀팁 | /tips | 숨김 |

가이드(/guides)는 카테고리가 아닌 별도 메뉴.

## 4. 핵심 파일 지도
- `src/config/categories.ts` — IA·APPROVAL_MODE·카테고리 색/이모지 (모든 기준)
- `src/components/CategoryLanding.tsx` — /money·/benefits 등 글 목록형 페이지 공용 틀
- `src/components/PostRow.tsx` — 글 목록 카드(가로형, **카테고리 색+이모지 썸네일**)
- `src/app/blog/[slug]/page.tsx` — **글 상세 공용 템플릿**(전 글 공통). 지원금/축제만 공식정보 블록, 나머지는 깔끔 에디터형
- `src/components/Header.tsx` / `Footer.tsx` — 네비·푸터(카테고리 SSOT 연동)
- `src/app/tools/{salary,loan,income-tax,insurance}` — 계산기 4종(연봉 실수령액·대출 이자·종합소득세·4대보험). 위젯은 `src/components/*Calculator.tsx`
- `src/app/about·terms·privacy·disclaimer·contact` — 정책/소개(지역·공공데이터 문구 정리됨)
- 빌드 스크립트: `scripts/validate-content.js`(콘텐츠 검증), `scripts/build-search-index.js`(검색 색인) — prebuild에서 실행

## 5. 새 글 쓰는 규칙
`src/content/posts/YYYY-MM-DD-english-name.md` 생성. frontmatter:
```
title / date / summary / description
category: 경제      # 경제→/money, benefit·정보→/benefits
tags: [..]
officialCurationNote: "..."   # ⭐ 에디터 한마디(선택)
```
- **이미지 필드 넣지 말 것** → 자동으로 카테고리 색 썸네일(경제=초록 💰). 글마다 이미지 불필요.
- 본문은 `##` 헤딩 + 표 + 내부링크(/tools·/money·/benefits). 수치엔 "2026 기준" + 면책 문구.
- 사실·숫자는 공식 자료로 확인, 확실치 않으면 단정 금지.
- **(절대 규칙) 같은 카테고리 기존 글 형식을 그대로 따른다.** 새 형식을 만들지 말 것. 경제 글 = 도입 → `## 한눈에 비교`(표) → `##` 섹션 → `## 자주 묻는 질문` → `## 마무리`(내부링크) → 면책.
- **(체류시간 규칙) 글 안에서 관련 글로 자연스럽게 넘어가는 내부 링크(글→글 루프)를 넣는다.** `## 마무리`에 형제 글 1~2개 + 본문 맥락 링크. 하단 '함께 읽으면 좋은 글'(자동, 같은 category 우선) 루프 유지.

### 2026-06-27 (2차) — 계산기 2종 추가 + 요율 검수
- 종합소득세 계산기 신설(`tools/income-tax`): 과세표준→누진세율(6~45%)→지방세→실효세율. 세율표·FAQ·내부링크 포함.
- 4대보험 계산기 신설(`tools/insurance`): 국민연금·건강·장기요양·고용 근로자 부담. 요율표·내부링크 포함.
- **요율 검수**: 국민연금 4.5%·건강 3.545%·장기요양=건강×12.95%·고용 0.9% 검색 확인. 국민연금 기준소득월액 상한 **617만→637만**(2025.7~2026.6)으로 salary 계산기까지 수정(+하한 40만).
- **수치 검산**: 종합소득세는 구간누적·누진공제 두 방식 전 구간 일치, 4대보험은 표준 계산기 값과 일치(node 검증). tsc EXIT 0.
- 양도세는 정확도 위험으로 제외(허브에서 4대보험으로 대체). 계산기 허브 4종 노출.
