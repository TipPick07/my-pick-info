## 0. 현재 위치 진단 (2026-07-02)

### 강점 (이미 갖춘 것)
- **고단가 주제 포지셔닝**: 대출·세금·보험·연금·투자는 광고 단가(RPM)가 높은 편인 금융 키워드. 방향 자체가 수익에 유리.
- **계산기 12종 + 가이드 10편 + 글 63편**: 계산기는 재방문·체류시간·백링크를 만드는 자산. 경쟁 블로그가 따라하기 어려움.
- **클러스터 구조**: 투자세금(주식·ETF·해외주식), 일·고용(내일배움카드·실업급여·연차수당), 노후연금(기초연금·3층연금·퇴직금) 등 허브-스포크가 이미 형성됨. 애드센스가 요구하는 "한 분야를 파고드는 전문성"과 일치.
- **인프라 완비**: GA4(G-5N4Y71B3ZQ)·GSC·네이버 서치어드바이저 인증·ads.txt·sitemap·robots·JSON-LD(Article/FAQ/Breadcrumb)·301 리다이렉트 정리·정책 페이지(약관·개인정보·면책·문의) 전부 있음.
- **콘텐츠 규격 통일 완료(7/2)**: 제목≤35자·설명≤90자·에버그린 마감·내부 루프 63/63편·게이트 경고 0.

### 약점 (수익을 막고 있는 것) — 우선순위 순
1. **트래픽 거의 0**: 5/23 이후 유입원(축제 글)을 삭제해 유입 급락. 새 글 색인·노출 회복이 최우선. → 콘텐츠는 준비됐고 **시간+꾸준한 발행**이 답.
2. **애드센스 4회 거부 이력**: "가치가 별로 없는 콘텐츠". 7/2 정리로 원인(짧은 글·중복 제목·만료 정보·잔재 필드)을 제거했으나, **색인이 안정된 뒤(빨라야 7월 중순) 신청**해야 5회차 거부를 피함. → `docs/SEO-CHECKLIST.md` 날짜별 체크 준수.
3. **구글 단일 의존**: 유입 채널이 사실상 구글뿐. 네이버·다음 검색, 오픈채팅 외 채널이 없음.
4. **지역 한정 얇은 글 잔존**: 일회성 행사(플랫폼P 강연), 초기 지역 글(은평 돌봄·성북 건보료 등)은 보강했지만 여전히 사이트 전문성 대비 이질적. (→ §5 통폐합 검토)
5. **E-E-A-T 신호 약함**: YMYL(돈·건강) 사이트인데 "누가 어떤 기준으로 검증하는가"가 약함.

## 2. 승인 후: 광고 수익 극대화

- **광고 배치 순서**: 자동광고로 시작(2주 데이터 수집) → 수동 최적화. 성과 좋은 위치 = 본문 첫 H2 위, 본문 중간, '함께 읽으면 좋은 글' 직전. 계산기 페이지는 **결과 카드 아래 1개만**(도구 페이지 과다 광고는 "가치 없는 화면" 정책 위반 위험).
- **앵커 광고·전면 광고** 켜기(모바일 수익 비중 큼). 단 이탈률 추이 관찰.
- **고RPM 클러스터 계속 확장**: 대출(주담대·전세대출·신용대출), 보험(자동차·실손), 세금(연말정산·종소세·양도세) — 이미 있는 축을 깊게. 새 축보다 기존 축 심화가 상위노출에 유리.
- 승인 후 숨김 3카테고리(핫이슈·나들이·꿀팁) 오픈 → **트래픽용(핫이슈) vs 수익용(경제·지원금) 역할 분리** 운영.

## 3. 트래픽 성장 (구글 상위노출 + CTR)

- **발행 리듬**: 주 3~5편, 클러스터 단위(글2+가이드1 또는 글2+계산기1 묶음). 산발적 10편보다 묶인 3편이 노출에 유리.
- **CTR 루틴(월 1회)**: GSC 실적 → "노출 많고 CTR 낮은" 상위 10개 쿼리 → 해당 글 제목·설명 개선. (7/2에 전 글 제목≤35자·키워드 앞배치 완료 → 이후는 데이터 기반으로만 수정)
- **신선도**: 오래된 글 수치를 분기마다 갱신하고 date는 유지하되 본문에 "2026년 ○월 확인" 표기. 연도 바뀔 때(2027.1) 세율·한도 일괄 업데이트 필수 — 에버그린 사이트의 생명선.
- **네이버·다음**: 네이버 서치어드바이저 색인 현황도 GSC처럼 주간 확인(한국 트래픽의 절반 이상이 네이버). 다음 검색등록(register.search.daum.net) 미등록이면 등록.
- **내부 루프(체류시간)**: 63/63 완료. 신규 글도 루프 필수(WRITING-GUIDE 규칙 유지). 다음 단계 — 카테고리 허브 상단에 '처음이라면 이 순서로' 큐레이션 3~4개 고정 노출 검토.
