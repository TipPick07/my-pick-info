# 팁픽 롱테일 키워드 지도 — 임신·출산·육아 (수익 1순위)

> **이 문서의 목적**: 부모 audience를 겨냥한 롱테일 키워드를 클러스터로 묶고, 각 키워드를
> 어떤 콘텐츠 타입(pillar 가이드 / 하위 가이드 / situations 카드 / .md 블로그)에 태울지,
> 그리고 어떤 순서로 작성할지를 정한 **작업 큐 겸 내부링크 설계도**. 5개 생애주기 중 첫 번째.
> 작성: 2026-06-05 | 연결 pillar: `/guides/parenting-family-benefits/` | 분류 허브: `/situations/parenting`

---

## 0. 사용법 (읽는 법)

- **검색의도** = 어떤 콘텐츠 타입에 맞는지 가르는 축.
  - `정보형` → pillar/가이드 본문에서 설명. `비교형` → 비교표·비교 .md(금융고리 붙이기 좋음).
    `거래형(신청)` → 신청 절차·창구 안내(원본 상세페이지·CTA로 연결).
- **클러스터** = pillar(육아·가족 가이드) 아래 묶음. 같은 클러스터 키워드는 한 가이드 안에서
  H2 섹션으로 모이거나, 하나의 하위 가이드로 분가한다.
- **매핑** = 그 키워드를 어디에 둘지의 결정.
  - `pillar 흡수` = 기존 parenting-family-benefits 본문에 H2/표로 보강.
  - `신규 하위가이드` = 검색의도가 독립적이라 별도 `/guides/<slug>/` 신설 후보.
  - `situations 카드` = 깊은 글 없이 /situations/parenting에 색인만(저수요·발견용).
  - `.md 블로그` = 마감 있는 한시·시즌성 단발(일일 후보 보고서에서 떠오르는 것).
  - `pillar 금융고리` = 수익 레이어. pillar 맥락 안에 제휴 비교를 자연스럽게 붙이는 자리.
- **우선순위** = `검색수요 × 수익잠재력` 2축(프로젝트 지침 §1).
  - `★최우선` = 고수익 고리(자녀 적금·청약·보험·전세대출 등) **또는** 압도적 고수요 유입 자석.
  - 셀의 괄호 표기: `(유입자석)` = 트래픽을 끌어옴 / `(수익고리)` = 방문자당 수익을 만듦.
  - 둘은 짝이다 — 유입자석이 부모를 데려오고, 그 페이지에 금융고리를 붙여 수익화한다.

## 1. 클러스터 구조 (pillar 아래 6묶음)

| 코드 | 클러스터 | 성격 | 수익 연결 |
|---|---|---|---|
| C1 | 현금성 지원 | 부모급여·아동수당·양육수당·첫만남 등 직접 현금 | 약(트래픽 핵심) |
| C2 | 보육·교육비 | 보육료·유아학비·누리과정·어린이집/유치원 | 약(트래픽) |
| C3 | 의료·건강 | 국민행복카드·영유아검진·예방접종·미숙아 | 약 |
| C4 | 출산·임신 단계 | 첫만남이용권·임신바우처·산후조리 | 중(지자체·시즌성) |
| C5 | 주거 연계 | 신생아 특례대출·다자녀 특공·전세 | **강(대출 비교)** |
| C6 | 금융 연계 | 자녀 적금·청약·자녀보험·디딤씨앗·자녀장려금 | **강(제휴 핵심)** |

> C1~C3는 **유입 자석**(부모가 가장 많이 검색, 직접 수익은 약함). C5·C6는 **수익 레이어**
> (제휴 CPS가 큼). 전략의 핵심은 C1~C3로 데려와 C5·C6로 수익화하는 동선이다.

## 3. 작업 큐 (이 지도로 다음에 뭘 만들지)

> 순서는 `수익 직결 × 기존 자산 활용도`로 정함. 케이던스 원칙대로 할당 아님 — 위에서부터.

1. **[보강] 기존 pillar `parenting-family-benefits` 업데이트** — ⓐ 아동수당 9세 확대(2026.4) 반영,
   수도권은 지역 추가분 없음을 명시 ⓑ 비워둔 **금융고리 자리 채우기**(C5·C6 ★최우선 키워드를
   맥락 링크로). *가장 싸고 즉효* — 이미 있는 페이지에 수익 레이어를 붙이는 것.
2. **[신규 ★] `육아 금융 가이드`** (가칭 slug: `parenting-family-finance`) — C6 전체 + C5 대출.
   자녀 적금·청약·어린이 보험·디딤씨앗·주식계좌 증여를 한 페이지에. **제휴 수익 직결 1순위 신규.**
3. **[신규] `어린이집·유치원 신청 가이드`** (가칭 `daycare-admission`) — C2 거래형(입소대기·국공립
   신청). 검색 pain이 크고 의도가 독립적이라 분가.
4. **[신규] `임신·출산 단계 지원 가이드`** (가칭 `pregnancy-birth-support`) — C4 + C3 거래형
   (첫만남·국민행복카드·임신바우처·산후조리). pillar의 *앞 단계*를 채워 생애주기 커버리지 확장.
5. **[.md 블로그 큐]** — 일일 후보 보고서에서 뜨면 가볍게:
   - 출산 가구 주거비 지원 (현재 보고서에 이벤트성으로 노출 중 · 마감 있음 → 우선)
   - 수도권 3시도(서울/경기/인천) 출산지원금 비교 (고유 콘텐츠·수도권 차별점)
   - 산후조리 경비 지자체별 (시즌·지역)

## 4. 2026 팩트 노트 (페이지 작성 시 주의)

- **아동수당 연령**: 2026.4부터 **9세 미만**으로 확대(보건복지부 법 개정). 2030년까지 매년 1세씩 →
  13세 미만 목표. **추가 지급(월 5천~2만 원)은 비수도권·인구감소지역 한정 → 수도권(서울·인천·경기)은
  대상 아님.** 팁픽 타깃엔 "초등 저학년도 이제 아동수당" 앵글이 신규 검색수요.
- **부모급여 월 금액**: 출처마다 갈림(100/50 유지설 우세, 일부 110/55·150/100). **이 지도엔 금액 미기재.**
  실제 페이지에 넣을 금액·차액(어린이집 보육료 공제)은 **반드시 복지로(bokjiro.go.kr)에서 확인 후** 기재.
- **금액·단가·소득기준 일반 원칙**: 이 지도는 *키워드·구조*만 다룬다. 모든 구체 수치는 pillar/가이드
  본문이 복지로·정부24 기준으로 검증해 싣고, 이 문서엔 넣지 않는다(수치 갱신을 한 곳으로 SSOT).

## 5. 갱신·연결 메모

- 이 지도는 **살아있는 문서**다. 새 키워드/제도 변경 시 §2 표에 행 추가, 새 가이드를 만들면 §3 큐에서 제거.
- **일일 후보 보고서**(`docs/daily-topic-report.md`)와의 관계: 보고서는 *지금 크롤된 한시·시즌 후보*
  (→ .md 블로그)를 떠올려주고, 이 지도는 *오래 갈 상록수 주제*(→ pillar/하위 가이드)를 정의한다.
  보고서에 뜬 이벤트성이 이 지도의 클러스터에 들어맞으면, .md로 쓰고 관련 가이드로 내부링크한다.
- 다음 생애주기 지도: 주거·전월세 / 청년 / 중장년·은퇴 / 장애인·돌봄 (각각 별도 `keyword-map-*.md`).
