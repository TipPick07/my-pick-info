## 2. 1단계 — 자동광고로 2주 (데이터 수집기)

**아무것도 손대지 말고 2주간 자동광고만 돌린다.** 구글이 위치·형식을 실험하며 데이터를 쌓는 기간.
매일 1분씩 애드센스 홈에서 ① 수익 ② 페이지 RPM ③ 노출 수만 기록해 둔다(§7 루틴 표).

2주 후 볼 것: GA4 이탈률이 승인 전보다 **크게(예: 10%p 이상) 나빠졌으면** 광고 로드를 한 단계 낮춘다. 전면광고가 거슬린다는 반응(오픈채팅 등)이 있으면 빈도 제한을 걸거나 끈다.

## 3. 2단계 — 수동 배치 최적화 (2주 후, 데이터 보고)

자동광고를 유지한 채, 성과가 확인된 위치에 **수동 인아티클 광고**를 추가·고정한다.
글 템플릿(`src/app/blog/[slug]/page.tsx`) **한 곳만 고치면 63편 전체에 적용**된다. (⚠️ .tsx = Python 수정, AI에게 "블로그 템플릿에 인아티클 광고 슬롯 추가해줘"라고 시키면 됨)

### 글 페이지 광고 지도 (우선순위 순)
| # | 위치 | 형식 | 이유 |
|---|---|---|---|
| 1 | 도입 문단 끝 ~ 첫 H2 사이 | 인아티클 | 첫 화면 근처, 노출·단가 최고 지점 |
| 2 | 본문 중간(2~3번째 H2 사이) | 인아티클 | 읽는 흐름 중간, 체류 긴 글에서 효자 |
| 3 | '자주 묻는 질문' 직전 | 인아티클 | 스크롤 깊은 독자 = 참여도 높음 |
| 4 | '함께 읽으면 좋은 글' 위 | 멀티플렉스 | 이탈 직전 마지막 수익 지점 |
| 모바일 공통 | 화면 하단 고정 | 앵커(자동) | 모바일 수익 비중 최대, 유지 |

### 페이지 유형별 규칙
- **계산기(/tools/)**: 결과 카드 아래 1개 + 하단 SEO article 중간 1개, **최대 2개**. 도구 화면에 광고 도배 = "가치 없는 화면" 정책 위험. 계산 버튼·입력창 바로 옆은 오클릭 유발이라 금지.
- **홈·카테고리 목록**: 자동광고에 맡김(수동 추가 안 함). 목록형은 과밀해 보이기 쉽다.
- **가이드(/guides/)**: 글 페이지와 동일 지도 적용 가능(각 page.tsx 개별 수정 필요, 트래픽 많은 가이드부터).

### 조정 루프 (2주 주기)
1. 애드센스 보고서 → "페이지" 기준 RPM 상위/하위 10개 확인
2. GA4 → 같은 페이지 이탈률·체류시간 비교
3. RPM 낮고 이탈 높은 위치 하나만 바꾼다(한 번에 하나씩 — 아니면 원인을 모름)

## 4. 정책 안전수칙 (위반 = 롱런 끝)

- ❌ **내 광고 클릭 절대 금지**(가족·지인 포함, 호기심 클릭도). 확인은 애드센스 보고서로만.
- ❌ "광고를 클릭해 주세요"류 문구, 화살표·이모지로 광고 가리키기 금지.
- ❌ 버튼·메뉴 바로 옆 광고(오클릭 유발 배치) 금지.
- ❌ 트래픽 구매·교환, 클릭 품앗이 금지.
- ✅ YMYL(돈) 사이트로서 과장·단정 금지 원칙 유지(이미 WRITING-GUIDE 규칙).
- ✅ 개인정보처리방침에 광고 쿠키 사용 문구 확인(승인 주에 1회 점검).
- 참고: 수익 급증·급락, 무효 트래픽 메일이 오면 → 애드센스 정책 센터부터 확인, 절대 방치하지 않기.

## 5. RPM을 구조로 높이기 (배치보다 크게 버는 곳)

### ① 발행 비중 = 단가 비중
광고 단가는 대체로 **대출·보험 > 세금·투자 > 지원금·생활** 순으로 높다. 주간 발행에서 **경제(금융) 글 비중을 절반 이상** 유지 — 지원금 글은 트래픽, 금융 글은 수익 담당.

### ② 계절 캘린더 (검색 피크 2~3주 전에 글 업데이트/발행)
| 월 | 돈 되는 시즌 주제 (기존 글 업데이트 우선) |
|---|---|
| 1월 | 연말정산 간소화 오픈, 자동차세 연납, 새해 바뀐 제도 |
| 2~3월 | 연말정산 환급 조회, 새 학기·청년 지원 공고 |
| 4월 | 건보료 정산, 종소세 예열 |
| 5월 | **종합소득세 + 근로·자녀장려금(연중 최대 시즌)** |
| 6~7월 | 에너지바우처·재산세 1기, 여름 지원 |
| 8~9월 | 주민세, 재산세 2기, 추석(문화누리·상여) |
| 10~11월 | 연말정산 미리보기, ISA·연금저축·IRP 막차(세액공제) |
| 12월 | **연금계좌 막차 + 자동차세 연납 신청 + 내년 달라지는 제도** |

### ③ 체류시간 = 노출 수
글→글 루프(63/63 완성)와 계산기 상호 링크가 페이지뷰/세션을 늘린다 → 같은 방문자로 광고 노출 2~3배. 신규 글 루프 규칙은 계속 필수.

## 6. 수익 다변화 (애드센스 하나에 안 기대기)

| 단계 | 시점(신호) | 실행 |
|---|---|---|
| 1 | 승인 직후 1개월 | 애드센스만 안정화. 다른 것 붙이지 않기 |
| 2 | 월 방문 1만+ | **쿠팡 파트너스**: 계산기·글과 궁합 맞는 상품만(자동차세→차용품, 육아→육아용품). 글당 1~2개, **"쿠팡 파트너스 활동으로 수수료를 제공받을 수 있습니다" 표기 의무** |
| 3 | 월 방문 5만+ | 금융 제휴 CPA(대출비교·카드 발급 등 제휴 플랫폼), 오픈채팅 → 뉴스레터 승격 |
| 4 | 브랜드 검색 발생 | 광고 직거래(푸터 문의·광고 메일 활용), 디지털 상품(엑셀 가계부·세금 캘린더 템플릿) |

⚠️ 어떤 단계든 **애드센스+제휴 링크가 한 화면에 몰리지 않게** — 광고 30% 원칙은 합산 기준으로 지킨다.
