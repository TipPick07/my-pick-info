## 🛠️ 404 줄이는 법 (선택, 효과 큼)

GSC → 페이지 → "찾을 수 없음(404)" → 예시 URL **내보내기**. 그중:
- **의미 있는 옛 URL**(검색 유입 있던 축제·글) → `public/_redirects`에 `옛URL  /blog/  301` 개별 추가(⚠️ 와일드카드 금지)
- 나머지 잡다한 크롤 URL → 그냥 두면 구글이 수 주 내 색인에서 제거(404 자체는 잘못 아님)

404 목록을 받아서 알려주면, 어떤 걸 301로 살릴지 같이 골라 드립니다.

## 📌 "정상"의 핵심 요약

- 404·리디렉션은 **시간이 지나며 줄어드는 게 정상**(어제 대량 삭제의 자연스러운 후유증). 늘어나면 점검.
- 색인 생성된 페이지는 **새 글로 다시 늘어나는 게 정상**.
- ads.txt는 **"찾을 수 없음" → "승인됨"**이 되어야 정상.
- 애드센스는 **사이트가 "정리되고 + 양질 콘텐츠가 색인된" 뒤** 신청해야 승인 확률이 오른다.
